# 研究者オンボーディングガイド

**対象者：** ラボのウェブサイトへの招待を受けたばかりの研究者
**目的：** アカウントの有効化を最初から最後まで順を追って説明する
**前提条件：** ラボの管理者からの招待リンク

> **パスワードは、ラボの管理者を含め、誰にも教えないでください。** パスワードを知っているのはあなただけです — 招待した管理者であっても、それを見たり、設定したり、復元したりすることはできません。

## 1. 招待を受け取る

管理者から、リンクが非公開で（メール、チャット、対面など）送られてきます — `https://<サイト>/invite/<長いランダムなコード>` のような形式です。このリンクはパスワードと同様に扱ってください。このリンク1つだけでアカウントを作成できてしまいます。使用できるのは**1回のみ**で、発行から**7日間**で期限切れになります。

## 2. 招待リンクを開く

ブラウザでリンクを開いてください。リンクが有効であれば、あなたのメールアドレスとともに短い有効化フォームが表示されます。「無効、期限切れ、または使用済みです」と表示された場合、そのリンクは再利用できません — 管理者に新しいリンクを依頼してください（すでに有効化した後に、誤って古いリンクをもう一度開いた場合にもこのメッセージが表示されます）。

## 3. 自分のパスワードを設定する

パスワード（8文字以上）を入力し、確認のためにもう一度入力します。これが、あなたがパスワードを設定する**唯一**の場面です — この過程のどこにおいても、管理者があなたの代わりにパスワードを選んだり、それを見たり、教えるよう求めたりすることはありません。フォームを送信してください。

## 4. 有効化

フォームを送信すると、アカウントが作成されると同時にログイン状態になります — 有効化直後に改めてログインする必要はありません。

## 5. プロフィールを完成させる

**アカウント → マイプロフィール**を開き、氏名、役職、所属、簡単な経歴を入力してください（写真URLは任意です）。これが、訪問者に表示される公開の研究員一覧ページの内容になります。

## 6. 研究情報を追加する

プロフィールを作成したら、以下のことができるようになります。

- 論文、ニュース項目、研究分野の追加
- プロジェクトや研究グループの作成・参加（プロジェクト／グループのリードやラボ管理者にメンバー追加を依頼するか、自分で新規作成する）
- 自分の研究に関連するラボのリソースやナレッジドキュメントの追加

作成したコンテンツは、ラボ管理者が公開するまで初期状態ではすべて**ラボ限定**（ログイン中のメンバーのみ閲覧可、一般には非公開）になります。意図せず一般公開されてしまうことはありません。

## 7. アカウント設定を確認する

**マイプロフィール**の**パスワード**セクションから、いつでもパスワードを変更できます（現在のパスワードの入力が必要です）。それ以外に設定できるアカウント項目はありません。役割やプロフィールのカテゴリーは管理者が管理します。

## 8. 以降は通常どおりログインする

今後は、ヘッダーの**ログイン**からメールアドレスと設定したパスワードでログインしてください。招待リンク自体はこの時点で完全に使用済みとなり、二度と機能しません — 招待リンクではなく `/login` をブックマークしてください。

## 9. 自分で編集できること・管理者が必要なこと

詳しい一覧は研究者/ラボメンバー向けガイドを参照してください。概要としては、自分のプロフィール・パスワード・自分のコンテンツは常に自分で編集できます。アカウントの役割、削除、他のメンバーのコンテンツにはラボ管理者または管理者の権限が必要です。

## 10. パスワード・セキュリティに関するベストプラクティス

- 他のサービスで使い回していないパスワードを選んでください。
- ラボの管理者を含め、誰にもパスワードを教えないでください — 正当な理由でパスワードを尋ねられることはありません。
- アカウントが侵害された可能性がある場合は、管理者に伝えてください。管理者はアカウントを無効化できます。再度有効化するには、新しい招待が必要になります。
- ログアウト状態で使える「パスワードをお忘れですか」機能は現時点ではありません — 管理者にご連絡ください。
