# クイックスタートガイド

**対象者：** サイトを初めて利用する方 — 一般訪問者も、招待されたばかりのメンバーも
**目的：** 約5分でサイトの使い方を把握する
**前提条件：** 特になし

## 1. サイトにアクセスする

ブラウザでサイトのURLを開いてください。閲覧にアカウントは不要です。

## 2. アカウントを有効化する（招待を受けた方のみ）

ラボの管理者から招待を受けている場合、非公開のリンク（`/invite/<トークン>`）が届いているはずです。リンクを開き、自分のメールアドレスが表示されていることを確認し、自分でパスワードを設定してください — 管理者を含め、誰もそのパスワードを知ることはありません。これによりアカウントが有効化され、すぐにログイン状態になります。（まだ招待を受けていない場合は、下記「お問い合わせ」を参照してください。）

## 3. ログインする

ヘッダーの**ログイン**をクリックし、メールアドレスとパスワードを入力します。ログイン後は、アカウントメニューに**ログアウト**があります。

## 4. プロフィールを完成させる

ログイン後、**アカウント → マイプロフィール**（`/profile`）を開きます。氏名、役職、所属、簡単な経歴、（任意で）写真URLを入力してください。これが公開の研究員一覧ページに表示される内容です。

## 5. 研究を探す

**研究**メニューから、研究分野、プロジェクト、論文・出版物、ナレッジドキュメント、ラボのリソースを閲覧できます。

## 6. 研究者を探す

**メンバー**メニューから、研究員一覧や研究グループを閲覧できます。名前をクリックすると、その人の公開プロフィール全体が表示されます。

## 7. 論文・プロジェクトを探す

`/publications` と `/projects` はいずれも絞り込みと検索に対応しています。研究分野のページからも、関連するすべての情報をまとめて確認できます。

## 8. メンバー向け機能を使う（ログイン後）

- **ワークスペース** — 自分が関わるプロジェクト・グループ・研究分野を一箇所で確認。
- **メッセージ**／**通知** — 非公開の会話と、自分宛てのアクティビティ。
- **コミュニティ → フォーラム** — 閲覧できるカテゴリーで投稿・コメント・リアクション。
- 論文、ニュース、研究分野、イベント、ナレッジドキュメント、リソース、ギャラリー項目を追加可能 — いずれもラボ管理者が公開するまでは初期状態でラボ限定です。

## 9. ヘルプを探す

詳しくは**一般訪問者ガイド**または**研究者/ラボメンバー向けガイド**を、直接ラボに連絡したい場合はヘッダーの**お問い合わせ**をご利用ください。

## 10. ログアウトする

どのページからでも、アカウントメニュー → **ログアウト**から行えます。
