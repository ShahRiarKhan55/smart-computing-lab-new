# 管理者ガイド

**対象者：** ラボの管理者およびラボ管理者
**目的：** サイトに実装されているすべての管理機能について、場所と安全な使い方を説明する。ラボ管理者の方は、下記「ラボ管理者にできること・できないこと」を参照してください。**管理者専用**と記載のあるセクションはラボ管理者には利用できません
**前提条件：** 管理者またはラボ管理者のアカウント（管理者ダッシュボードの大部分に必要。アカウント・招待の管理は管理者専用 — 下記「役割について」を参照）。

## 役割について（概要）

このアプリには**メンバー**・**ラボ管理者**・**管理者**の3つの役割しかありません（アカウント管理を除き、後の役割は前の役割の権限をすべて含みます）。アプリ内に「サイトオーナー」という独立した役割はありません — それはVercelやTursoのダッシュボードを操作するあなた自身の役割です（サイトオーナー/運用者向けガイドを参照）。

| 機能 | メンバー | ラボ管理者 | 管理者 |
|---|:---:|:---:|:---:|
| 自分のプロフィール・コンテンツ | ✓ | ✓ | ✓ |
| 管理者ダッシュボード、コンテンツ管理、公開範囲、モデレーション | | ✓ | ✓ |
| アカウント：招待、作成、削除、役割変更 | | | ✓ |
| プロジェクト・グループの作成、他の人の（卒業生以外の）プロフィールの編集、コンテンツの削除 | | ✓ | ✓ |
| 卒業生：追加・編集・公開・非公開、未公開の卒業生の閲覧 | | | ✓ |
| 研究員プロフィールの削除 | | | ✓ |

権限の完全な一覧表は、リポジトリの `docs/technical/role-permissions.md` にあります。

## ラボ管理者にできること・できないこと

**できること：** 管理者ダッシュボード（概要、研究コンテンツ、イベント、コミュニティ、ファイルとギャラリー、多言語化、監査ログ）の利用。あらゆる記録の公開範囲の変更（一括変更を含む）。論文・ニュース・研究分野の削除。プロジェクトやグループの作成と、すべてのプロジェクト・グループの編集。教員・博士課程・修士課程・学部生・研究生カテゴリーの研究員プロフィールの作成と、他の人のプロフィール（カテゴリーや表示順を含む）の編集。重複警告の確認（「それでも保存」）。フォーラムのモデレーションとカテゴリー管理。メンバーが作成したイベント・ナレッジ・リソース・ギャラリー項目の編集・削除。日本語版（オーバーライド）の編集。

**できないこと（管理者専用）：** アカウントの招待・削除、役割変更、アカウントとプロフィールのリンク、「メンバーとアカウント」の利用。**卒業生**プロフィールの作成・編集・移動・公開・非公開（ラボ管理者には一般の訪問者と同じ内容、つまり公開済みの卒業生だけが研究員一覧ページに表示されます）。研究員プロフィールの削除。これらは直接APIを呼び出してもサーバーが拒否します。承認キューはありません。メンバーの論文・ニュース・研究分野はすぐに公開され、ラボ管理者が後から修正・削除します。

## 管理者ログインとダッシュボード

`/login` から管理者またはラボ管理者のアカウントでログインし、ヘッダーの**アカウント → 管理者ダッシュボード**（直接アクセスする場合は `/admin`）を開いてください。ダッシュボードの概要ページには、アカウント数やコンテンツ数の概況が表示されます。

## 研究者の招待（オンボーディング）— 管理者専用

**場所：** 管理者ダッシュボード → **メンバーとアカウント**（`/admin/people`）
**内容：** パスワードを一切見ることも設定することも受け取ることもなく、新しい研究者を招待します。
**必要な権限：** 管理者のみ。ラボ管理者にはこのセクション自体が表示されず、直接APIを呼び出そうとしてもサーバー側で拒否されます。

**手順：**

1. 「メンバーとアカウント」を開き、**研究者を招待**をクリックします。
2. 招待する研究者のメールアドレスを入力し、アカウントの役割（メンバー／ラボ管理者／管理者）を選択します。
3. 研究員プロフィールの扱いを選択します：既存の未リンクのプロフィールにリンクする、新しいプロフィールを作成する（氏名、イニシャル、役職、カテゴリー）、またはプロフィールなし（アカウントのみのログイン）。
4. **招待リンクを生成**をクリックします。ダイアログに1回限り有効なリンクが表示されるので、**リンクをコピー**をクリックします。
5. そのリンクを研究者本人に**非公開で**（メール、チャット、対面など）送ってください。公開の場所には絶対に投稿しないでください。
6. ダイアログを閉じます。**このリンクは二度と表示されません** — このサーバーは生のリンクを保存せず、一方向のハッシュのみを保持します。研究者に届く前に紛失した場合は、取り消して新しい招待を生成してください。

**生成後の確認事項：** 同じページの**招待の一覧（保留中・過去分）**に、すべての招待の状態（保留中・承諾済み・期限切れ・取り消し済み）、送信者、期限が表示されます。研究者が承諾すると、上部のアカウント一覧にそのアカウントが表示されます。

**取り消し：** 保留中の招待には**取り消す**ボタンがあり、クリックすると即座に無効化されます。宛先を間違えた場合や不要になった場合に使用してください。取り消し済み・期限切れのリンクを元に戻すことはできません — 新しい招待を生成してください。

**よくある間違い：**
- リンクを半公開の場所（共有チャンネル、他者にも見えるチケットなど）に貼り付けてしまう — パスワードと同様に扱ってください。
- 同じメールアドレスに保留中の招待がある状態で、もう一度招待しようとする — システムはこれを拒否します（最初の招待を取り消すか、使用・期限切れを待ってください）。
- 研究者のパスワードをどこかで確認できると期待すること — 設計上、いかなる時点でも表示されません。

**セキュリティに関する考慮事項：** すべての招待トークンは256ビットの乱数値で、保存されるのはそのSHA-256ハッシュのみです。1回限り有効で、7日間で期限切れとなり、招待の作成・取り消し・承諾はすべて監査ログに記録されますが、トークン自体が記録されることはありません。

## 既存アカウントの管理

引き続き**メンバーとアカウント**（`/admin/people`）ページ：**アカウント**一覧には、すべてのログイン、その役割、研究員プロフィールへのリンク有無が表示されます。

- **役割の変更**：任意のアカウント（自分自身を除く — 自分の役割は変更できません。これにより管理者が最低1人は常に残ることが保証されます）の役割をドロップダウンから変更できます。
- **研究員プロフィールのリンク／解除**：既存のログインを既存の未リンクのプロフィールに接続、または接続を解除します（プロフィール自体は削除されず、リンクが解除されるだけです）。
- **アカウントの削除**：ログインのみを削除します。リンクされていた研究員プロフィール（ある場合）は保持され、リンクが解除された状態になります。

## コンテンツ管理

管理者ダッシュボードのその他のセクションは、ラボ管理者がすでに通常のサイトから行える操作の管理ビューであり、上記「役割について」に記載した以上の権限を追加するものではありません。

- **研究コンテンツ**（`/admin/content`）：コンテンツタイプを横断して閲覧できる一覧。公開範囲（公開／ラボ限定、一括変更含む）の管理。
- **イベント**（`/admin/events`）：ラボのイベントを管理します。
- **コミュニティ**（`/admin/community`）：フォーラムカテゴリーの管理とモデレーション。
- **ファイルとギャラリー**（`/admin/files`）：アップロードされたファイルとギャラリー項目を管理します。
- **多言語化**（`/admin/translations`）：翻訳可能なコンテンツの日本語版（オーバーライド）を管理します。
- **監査ログ**（`/admin/audit`）：アクティビティログ。誰が何をいつ行ったかを確認できます。アカウント関連のイベント（アカウントの作成・削除、役割変更、招待の作成・承諾・取り消し）は管理者のみ閲覧可能で、また、卒業生や未公開プロフィールに関する行もラボ管理者には表示されません。それ以外の監査対象操作はラボ管理者であれば閲覧できます。

## 研究員プロフィールと卒業生

**研究員一覧ページ**（`/team`）：セクションは教員、博士課程学生、修士課程学生、学部生、研究生、**卒業生**の順に並びます。卒業生は同じページの最後のセクションで、独立した卒業生ページやメニュー項目はありません（`/alumni` は `/team#alumni` に移動します）。閲覧者に見える卒業生がいない間、卒業生セクションは表示されません。

**研究員を追加する（ラボ管理者・管理者）：** 研究員一覧ページで**+ チームメンバーを追加**をクリックし、フォームに入力してカテゴリーを選びます。ラボ管理者が選べるのは教員・博士課程・修士課程・学部生・研究生で、**卒業生のカテゴリーが選べるのは管理者だけ**です。

**卒業生プロフィールを追加する（管理者専用）：**

1. `/team` で**+ チームメンバーを追加**をクリックします。
2. 氏名、イニシャル、役職を入力し、カテゴリーに**卒業生**を選びます。卒業生プロフィールは**未公開**で作成され、ログインアカウントを持つことはできません。
3. 保存します。カードは卒業生セクションに管理者だけに表示され、**未公開**と表示されます。
4. ご本人が掲載に同意したら、カードの**公開する**をクリックして確認します。次のリクエストから一般に公開されます。**非公開にする**でいつでも元に戻せます。

**ルール：** ラボ管理者に見えるのは公開済みの卒業生だけで、管理はできません。ログインアカウントにリンクされているプロフィールは卒業生に移動できません（先にアカウントのリンクを解除してください）。公開状態は公開する／非公開にするボタンでのみ変更できます。

**研究員プロフィールの削除（管理者専用・元に戻せません）：** プロフィール本体と、その経歴および論文・プロジェクト・グループ・研究分野へのリンクが削除されます。論文などの記録自体とリンク先のログインは残ります（ログインはリンクが解除された状態になります）。

## 論文と出版メタデータ

ログイン中のメンバーなら誰でも論文を追加・編集できます。削除と公開範囲の設定はラボ管理者・管理者が行います。フォームの**出版メタデータ**セクションには、任意の8項目があります：**状況**（出版済み・受理・投稿中）、**論文カテゴリー**、**雑誌リスト番号**、**巻**、**開始ページ**、**終了ページ**、**発行月**（1〜12）、**受理年月日**（`YYYY-MM-DD`）。ページは整数で、終了ページは開始ページより前にできません。空欄は「記載なし」として扱われ、訪問者には表示されません。受理・投稿中の論文は、検索エンジンに対して出版済みとは記述されません。**追加する前に必ず検索してください。** 同じDOIは常に拒否され、同じタイトルと発表年は、ラボ管理者または管理者が別の論文であると確認しない限り拒否されます。

## 破壊的・元に戻せない操作

| 操作 | 実行できる人 | 結果 |
|---|---|---|
| アカウントの削除 | 管理者 | ログインが削除され、研究員プロフィールは残ります（リンク解除）。再びアクセスするには新しい招待が必要です。 |
| 研究員プロフィールの削除 | 管理者 | プロフィール・経歴・リンクが削除されます。サイトからは元に戻せません。 |
| 論文・ニュース・研究分野の削除 | ラボ管理者・管理者 | 記録とそのリンクが削除されます。 |
| 招待の取り消し | 管理者 | リンクは即座に無効になり、復活できません。新しい招待を作成してください。 |
| 卒業生プロフィールの非公開化 | 管理者 | 公開の研究員一覧、検索、リンクからただちに消えます。再度公開すれば元に戻せます。 |
| 役割の変更 | 管理者 | その人の次のリクエストから反映されます。自分自身の役割は変更できません。 |

元に戻す機能やゴミ箱はありません。データの復旧については、サイト運用者向けのバックアップの説明（Tursoのポイントインタイムリカバリ）を参照してください。

## アカウントのライフサイクル（一連の流れ）

1. **招待**（管理者）→ 2. **研究者が自分でパスワードを設定して承諾** → 3. 他のアカウントと同様にアクティブな状態になる → 4. 必要に応じて役割変更・プロフィールのリンク（管理者）→ 5. 退職時などは**削除**（管理者）— 研究員プロフィールとその人が作成したコンテンツは保持され、単にログインとの紐付けが解除されます。

## 招待の安全な取り扱い — まとめ

- 招待リンクは認証情報の一種です。パスワードと同様に非公開で送付し、正しい相手にのみ届いたか確信が持てない場合は取り消してください。
- 招待時にも、その後も、研究者のパスワードを目にすることも知る必要もありません。
- 研究者がパスワードを忘れてロックアウトされた場合、現時点では自己解決型のリセット機能はありません — 古いアカウントを削除し、新しい招待を送ってください（詳細はサイトオーナー/運用者向けガイドの「既知の制限事項」を参照）。
- 「無効化」や「一時停止」の操作はありません。ログインを使えなくする方法は、アカウントの削除だけです。
- 管理者ダッシュボードでアカウントを作成する方法は招待のみです。（APIには管理者が決めたパスワードでアカウントを作成するエンドポイント `POST /api/users` もありますが、ダッシュボードでは使われていません。誰のパスワードも知らずに済むよう、招待を使ってください。）

## よくある問題

- **「管理者のみが卒業生プロフィールを管理できます」（403）。** ラボ管理者が卒業生の操作を行おうとしました。管理者に依頼してください。
- **「ログインアカウントを持つプロフィールは卒業生に移動できません」（409）。** 「メンバーとアカウント」で先にアカウントのリンクを解除してください。
- **リリース後にページがエラーになる。** データベースのマイグレーションがまだ適用されていない可能性があります。サイト運用者に連絡してください（`docs/technical/troubleshooting.md` を参照）。
