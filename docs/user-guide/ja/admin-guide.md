# 管理者ガイド

**対象者：** ラボの管理者およびラボ管理者
**目的：** サイトに実装されているすべての管理機能について、場所と安全な使い方を説明する
**前提条件：** 管理者またはラボ管理者のアカウント（管理者ダッシュボードの大部分に必要。アカウント・招待の管理は管理者専用 — 下記「役割について」を参照）。

## 役割について（概要）

このアプリには**メンバー**・**ラボ管理者**・**管理者**の3つの役割しかありません（アカウント管理を除き、後の役割は前の役割の権限をすべて含みます）。アプリ内に「サイトオーナー」という独立した役割はありません — それはVercelやTursoのダッシュボードを操作するあなた自身の役割です（サイトオーナー/運用者向けガイドを参照）。

| 機能 | メンバー | ラボ管理者 | 管理者 |
|---|:---:|:---:|:---:|
| 自分のプロフィール・コンテンツ | ✓ | ✓ | ✓ |
| 管理者ダッシュボード、コンテンツ管理、公開範囲、モデレーション | | ✓ | ✓ |
| アカウント：招待、作成、削除、役割変更 | | | ✓ |

## 管理者ログインとダッシュボード

`/login` から管理者またはラボ管理者のアカウントでログインし、ヘッダーの**アカウント → 管理者ダッシュボード**（直接アクセスする場合は `/admin`）を開いてください。ダッシュボードの概要ページには、アカウント数やコンテンツ数の概況が表示されます。

## 研究者の招待（オンボーディング）— 管理者専用

**場所：** 管理者ダッシュボード → **メンバー**（`/admin/people`）
**内容：** パスワードを一切見ることも設定することも受け取ることもなく、新しい研究者を招待します。
**必要な権限：** 管理者のみ。ラボ管理者にはこのセクション自体が表示されず、直接APIを呼び出そうとしてもサーバー側で拒否されます。

**手順：**

1. 「メンバー」を開き、**研究者を招待**をクリックします。
2. 招待する研究者のメールアドレスを入力し、アカウントの役割（メンバー／ラボ管理者／管理者）を選択します。
3. 研究員プロフィールの扱いを選択します：既存の未リンクのプロフィールにリンクする、新しいプロフィールを作成する（氏名、イニシャル、役職、カテゴリー）、またはプロフィールなし（アカウントのみのログイン）。
4. **招待リンクを生成**をクリックします。ダイアログに1回限り有効なリンクが表示されるので、**リンクをコピー**をクリックします。
5. そのリンクを研究者本人に**非公開で**（メール、チャット、対面など）送ってください。公開の場所には絶対に投稿しないでください。
6. ダイアログを閉じます。**このリンクは二度と表示されません** — このサーバーは生のリンクを保存せず、一方向のハッシュのみを保持します。研究者に届く前に紛失した場合は、取り消して新しい招待を生成してください。

**生成後の確認事項：** 同じページの**招待の一覧（保留中・過去分）**に、すべての招待の状態（保留中・承諾済み・期限切れ・取り消し済み）、送信者、期限が表示されます。研究者が承諾すると、上部のアカウント一覧にそのアカウントが表示されます。

**取り消し：** 保留中の招待には**取り消す**ボタンがあり、クリックすると即座に無効化されます。宛先を間違えた場合や不要になった場合に使用してください。取り消し済み・期限切れのリンクを元に戻すことはできません — 新しい招待を生成してください。

**よくある間違い：**
- リンクを半公開の場所（共有チャンネル、他者にも見えるチケットなど）に貼り付けてしまう — パスワードと同様に扱ってください。
- 同じメールアドレスに保留中の招待がある状態で、もう一度招待しようとする — システムはこれを拒否します（最初の招待を取り消すか、使用・期限切れを待ってください）。
- 研究者のパスワードをどこかで確認できると期待すること — 設計上、いかなる時点でも表示されません。

**セキュリティに関する考慮事項：** すべての招待トークンは256ビットの乱数値で、保存されるのはそのSHA-256ハッシュのみです。1回限り有効で、7日間で期限切れとなり、招待の作成・取り消し・承諾はすべて監査ログに記録されますが、トークン自体が記録されることはありません。

## 既存アカウントの管理

引き続き**メンバー**（`/admin/people`）ページ：**アカウント**一覧には、すべてのログイン、その役割、研究員プロフィールへのリンク有無が表示されます。

- **役割の変更**：任意のアカウント（自分自身を除く — 自分の役割は変更できません。これにより管理者が最低1人は常に残ることが保証されます）の役割をドロップダウンから変更できます。
- **研究員プロフィールのリンク／解除**：既存のログインを既存の未リンクのプロフィールに接続、または接続を解除します（プロフィール自体は削除されず、リンクが解除されるだけです）。
- **アカウントの削除**：ログインのみを削除します。リンクされていた研究員プロフィール（ある場合）は保持され、リンクが解除された状態になります。

## コンテンツ管理

管理者ダッシュボードのその他のセクションは、ラボ管理者がすでに通常のサイトから行える操作の管理ビューであり、上記「役割について」に記載した以上の権限を追加するものではありません。

- **コンテンツ**（`/admin/content`）：コンテンツタイプを横断して閲覧できる一覧。公開範囲（公開／ラボ限定、一括変更含む）の管理。
- **イベント**（`/admin/events`）：ラボのイベントを管理します。
- **コミュニティ**（`/admin/community`）：フォーラムカテゴリーの管理とモデレーション。
- **ファイル**（`/admin/files`）：アップロードされたファイルとギャラリー項目を管理します。
- **翻訳**（`/admin/translations`）：翻訳可能なコンテンツの日本語版（オーバーライド）を管理します。
- **監査**（`/admin/audit`）：アクティビティログ。誰が何をいつ行ったかを確認できます。アカウント関連のイベント（アカウントの作成・削除、役割変更、招待の作成・承諾・取り消し）は管理者のみ閲覧可能で、それ以外の監査対象操作はラボ管理者であれば閲覧できます。

## ORCIDから検出された研究業績と卒業生ディレクトリ

- **検出された研究業績の確認**（ラボ管理者・管理者）：研究業績ページで **検出された業績を確認** を選びます。**ORCIDを今すぐ確認** を押すと、プロフィールにORCID iDを登録している現役の研究者全員の、ORCID上の公開業績を読み取ります。結果は **確認待ち** に入り、**「承認して公開」を押すまで何も公開されません**。承認前にタイトル・著者・掲載先・公開範囲を修正できます。著者は必須で、DOIがある場合はCrossrefから取得され、ない場合は入力してください。**却下** した項目は二度と提案されません。DOIがすでにラボの一覧にある項目は **登録済み（重複）** に分類されます。
- 確認が *一部のみ成功* で終わることがあります。ORCIDの記録を読み取れなかった研究者（サービスが遅い・利用できない、iDが誤り）は集計され、残りは処理されます。後でもう一度お試しください。同時に実行できる確認は1つだけです。
- ORCIDで見つかるのは、各自が自分のORCIDレコードで公開している業績のみのため、見落としがあります。不足分は手動で追加してください。Google ScholarやResearchGateのスクレイピングは行いません。
- **卒業生**（`/alumni`）：**卒業生** カテゴリで元メンバーを追加します。卒業生のプロフィールにはログインがなく、アカウントの作成・リンク・招待はシステムが拒否します。**このプロフィールを公開する** のチェックを外すと、プロフィールページ・写真・一覧（チーム、卒業生、検索、サイトマップ）が訪問者から非表示になります。プロジェクトやグループのメンバー、論文の著者として明示的に紐づけられている箇所や、著者欄などの自由記述の名前は **削除されません**。完全に消す必要がある場合は、それらの紐づけを別途編集してください。
- **Googleログイン：** 設定済みの場合、指定されたラボのGoogleアカウントでGoogleログインができます。管理者がリンクしていない他のGoogleアカウントは拒否されます。パスワードログインはどちらの場合も引き続き使えます。
- **著作権の表示はどこ？** フッターと `/copyright` にあります。一般的な文言であり、法的助言ではありません。

## アカウントのライフサイクル（一連の流れ）

1. **招待**（管理者）→ 2. **研究者が自分でパスワードを設定して承諾** → 3. 他のアカウントと同様にアクティブな状態になる → 4. 必要に応じて役割変更・プロフィールのリンク（管理者）→ 5. 退職時などは**削除**（管理者）— 研究員プロフィールとその人が作成したコンテンツは保持され、単にログインとの紐付けが解除されます。

## 招待の安全な取り扱い — まとめ

- 招待リンクは認証情報の一種です。パスワードと同様に非公開で送付し、正しい相手にのみ届いたか確信が持てない場合は取り消してください。
- 招待時にも、その後も、研究者のパスワードを目にすることも知る必要もありません。
- 研究者がパスワードを忘れてロックアウトされた場合、現時点では自己解決型のリセット機能はありません — 古いアカウントを削除（またはそのまま）し、新しい招待を送ってください（詳細はサイトオーナー/運用者向けガイドの「既知の制限事項」を参照）。
