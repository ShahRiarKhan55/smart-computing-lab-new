# 研究者/ラボメンバー向けガイド

**対象者：** 研究者、学生、教員、その他ログイン済みのラボメンバー
**目的：** ログイン後に利用できるすべての機能 — アカウント、プロフィール、共同作業機能について説明する
**前提条件：** 有効なラボアカウント。まだお持ちでない場合は、下記「アカウントの有効化」または別紙「研究者オンボーディングガイド」を参照してください。

## アカウントの有効化

ラボのアカウントは管理者のみが作成でき、一般向けの登録フォームはありません。管理者があなたを招待すると、**7日間**有効・**1回限り**使用できる非公開のリンク（`/invite/<トークン>`）が発行されます。リンクを開くとメールアドレスが表示され、自分でパスワードを設定するフォームが表示されます。招待した管理者がそのパスワードを見たり、設定したり、受け取ったりすることは一切ありません — パスワードを知っているのはあなただけです。フォームを送信するとアカウントが有効化され、すぐにログイン状態になります。詳しい手順は研究者オンボーディングガイドを参照してください。

招待リンクの期限が切れている、またはすでに使用済みの場合は、管理者に新しいリンクを依頼してください。古いリンクを再利用したり、期限を延長したりすることはできません。

## ログインとログアウト

ヘッダーの**ログイン**（`/login`）からメールアドレスとパスワードを入力してください。ログイン後は、アカウントメニューに**ログアウト**があります。セッションは約1週間（最終操作から）有効です。再度ログインすることはいつでも安全に行えます。

ラボがGoogleログインを有効にしている場合、ログインページにも表示されますが、すでにリンク済みのアカウントでのみ使えます。パスワードでログインした状態で**マイプロフィール**を開き、そこでGoogleアカウントを接続してください。Googleでアカウントが新規作成されることはありません。

## パスワードの変更

**マイプロフィール**ページ（`/profile`）の**パスワード**セクションから、いつでも自分のパスワードを変更できます。現在のパスワードと新しいパスワードを入力してください。この操作に管理者が関わることは一切なく、現在のパスワードを知っている本人だけが変更できます。ログアウト状態でパスワードを忘れてしまった場合の自己解決型の「パスワードをお忘れですか」機能は現時点ではありません — 管理者に連絡してください。管理者は古いアカウントを削除し、新しい招待を送ることができます（研究員プロフィールとあなたが作成したコンテンツは残ります）。

## プロフィール

`/profile` には、アカウントにリンクされた自分の研究員プロフィール（まだリンクされていない場合は管理者に依頼してください）が表示され、以下の項目を編集できます。

- 氏名、イニシャル、役職、所属、簡単な経歴
- 写真：画像のアップロード（JPEG・PNG・WebP・GIF、5 MBまで。写真のメタデータは自動的に削除されます）または外部の写真URLの貼り付け
- Google Scholar・ResearchGate・ORCIDのプロフィールへのリンク（いずれも任意）

**カテゴリー**（教員・博士課程・修士課程・学部学生・研究員など）や一覧での表示順は、管理者またはラボ管理者が設定するもので、本人が変更することはできません。これは名簿の整理を一貫させるためです。公開プロフィール（`/team/:id`）は、リンク先がラボ限定に設定されている場合を除き、ゲストを含む誰でも閲覧できます。

## 自分で編集できること・管理者が必要なこと

| 自分で行えること | ラボ管理者・管理者が必要なこと |
|---|---|
| 自分のプロフィール項目の編集 | アカウントの役割（ロール）の変更 |
| 自分のパスワードの変更 | アカウントの作成・削除 |
| 論文・ニュース・研究分野の作成・編集 | それらの削除、公開範囲（公開／ラボ限定）の変更、重複警告の確認 |
| 自分が作成したイベント・ナレッジ・リソース・ギャラリー項目の作成・編集・削除 | 他のメンバーが所有するコンテンツの編集・削除 |
| 自分がリードを務めるプロジェクト・グループの編集 | プロジェクト・グループの作成や設定変更、他の人のプロフィールの編集 |
| — | **卒業生**プロフィールの追加・編集・公開（管理者のみ） |
| フォーラムへの投稿・コメント・リアクション | フォーラムのモデレーション（他者の投稿のピン留め・ロック・非表示・移動・削除） |
| 他のメンバーへのメッセージ送信、自分の通知の管理 | — |

**ラボ管理者**は上記に加えて、より広いコンテンツ管理権限（公開範囲、削除、プロジェクト／グループ設定、モデレーション、管理者ダッシュボード）を持ちますが、アカウント・役割の管理は常に管理者専用です。

## 研究・共同作業

- **プロジェクト・研究グループ**（`/projects`、`/groups`）：ラボ管理者または管理者が作成します。プロジェクトやグループの**リード**は、その編集とメンバー構成の管理ができます。
- **ワークスペース**（`/workspace`、ログイン時のみ）：自分が関わっているプロジェクト・グループ・研究分野を一覧できる個人用ビューです。
- **論文・ニュース・研究分野**：ログイン中のメンバーなら誰でも追加できます。
- **ナレッジ**（`/knowledge`）：ドキュメントを追加できます。自分のものはいつでも編集・削除でき、ラボ管理者になれば他者のものも編集できます。
- **リソース**（`/resources`）：ラボのリソース・インフラ情報を追加できます。所有権のルールはナレッジと同じです。
- **イベント**（`/events`）：イベントを作成できます。自分が作成したものは編集・削除できます。
- **ギャラリー**（`/gallery`）：写真を追加できます。自分のものは編集・削除できます。

**保存する前に公開範囲を確認してください。** 論文・ニュース・研究分野は**作成するとすぐに公開**されます（ゲストにも見えます）。作成時に公開範囲を選ぶことはできませんが、ラボ管理者が後から変更できます。イベント・ナレッジドキュメント・リソース・ギャラリー項目は、ラボ管理者または管理者が公開するまで、初期状態で**ラボ限定**（ログイン中のメンバーのみ閲覧可）です。

**重複。** すでに存在する論文・ニュース・研究分野（同じDOI、または同じタイトルと発表年）を追加しようとすると、重複警告で保存が止まります。既存の記録を検索して、そちらを編集してください。似ていても別物であると確認できるのはラボ管理者または管理者のみで、同一のDOIは常に拒否されます。

**論文。** 論文の追加・編集フォームには、任意の**出版メタデータ**セクション（状況、論文カテゴリー、雑誌リスト番号、巻、開始ページ、終了ページ、発行月、受理年月日）があります。論文に記載がない項目は空欄のままにしてください。空欄は表示されません。詳細は管理者ガイドを参照してください。

**スケジュール。** ログイン中は、ヘッダーに**スケジュール**（`/schedule`）も表示されます。ラボ共有のカレンダーです。

## コミュニティ

- **フォーラム**（`/community/forum`）：閲覧できるカテゴリーであれば、トピックの投稿・コメント・リアクションができます。自分の投稿・コメントは常に編集可能です。ラボ管理者はモデレーションとして非表示・ロック・ピン留め・移動・削除を行うことがあります。
- **メッセージ**（`/messages`、ログイン時のみ）：他のメンバーとの一対一の非公開会話です。管理者を含め、他の誰もあなたのメッセージを読むことはできません。
- **通知**（`/notifications`）：メンション、返信、リアクションなど、あなた宛てのアクティビティが表示されます。

## 公開範囲・プライバシーのルール（概要）

- コンテンツは**公開**（ゲストを含む誰でも閲覧可）または**ラボ限定**（ログイン中のメンバーのみ）のいずれかで、変更できるのはラボ管理者・管理者のみです。
- 非公開メッセージは、自分と相手の参加者のみが閲覧できます。
- プロフィールには、本人またはラボ管理者が入力した内容のみが表示され、リンク先のコンテンツにはそれぞれの公開範囲設定が適用されます。

## よくある問題

- **「アカウントにまだ研究員プロフィールがリンクされていません」と表示される。** ログインはできていますが、研究者プロフィールにリンクされていません。管理者にリンクまたは作成を依頼してください。
- **「権限がありません（403）」と表示される。** ログインはできていますが、その操作にはラボ管理者または管理者の権限が必要です（例：プロジェクトの作成、卒業生に関する操作）。
- **論文の保存時に「重複」の警告が出る。** すでに存在します。検索して、その記録を編集してください。
- **招待リンクが機能しない。** すでに使用済みか、期限（7日間）が切れています。管理者に新しいリンクを依頼してください。
